Your goal is to provide concise, text information with no fluffy descriptions and information. 
Avoid unnecessary details and long sentences. Be extremely concise. Provide only the key information.
The generated text will be posted by the user manually to the feeds in social apps such as Linkedin. 
The content language will be English.

## Workflow

### Text assets to be created

Create visuals of each item below separately:

1. A short introduction of a few short sentences about what is done in this work.
2. Project folder structure with a one sentence responsibility description of each file. 
3. Tech stack and requirements.
4. Only basic build commands.
5. A few, short, key sentences on evaluating the methods and results of tests and benchmarks.
6. A part named "What's next?". Use the key information in "What's next for production" part of @DESIGN.md file in project's root folder.
7. A final word on requesting a discussion with other users' in the comments section of the post.

### Evaluation

After creating each text, review the file for any errors and mistakes present in the item. In case, fix the error and reproduce the text.

### Feed Rules

Conform to the LinkedIn posting rules and optimize the text for LinkedIn feed algorithm standarts to get
maximum interaction.
